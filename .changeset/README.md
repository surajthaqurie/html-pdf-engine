# Changesets

Welcome! This repository uses [Changesets](https://github.com/changesets/changesets) for managing versioning and changelogs.

## Adding a Changeset

When making changes that impact consumers of `html-pdf-engine`, create a changeset by running:

```bash
npx changeset
```

Follow the prompts to select the change type (`patch`, `minor`, or `major`) and describe the changes made.
