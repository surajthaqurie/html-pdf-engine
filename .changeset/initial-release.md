Initial stable release of html-pdf-engine, a lightweight and deterministic HTML/CSS-to-PDF engine for structured document generation.

Includes deterministic PDF rendering, document metadata, internal navigation, hardened PDF serialization, expanded CSS support, configurable asset resolution, render-scoped state isolation, and comprehensive regression coverage.

The engine is designed for structured document generation and is not intended to provide full browser rendering compatibility.
